# Лабораторна робота №2 — Flask сайт "Резюме"

## 📄 Опис
Цей проєкт — невеликий вебсайт із двох сторінок: **"Резюме"** та **"Контакти"**, створений за допомогою фреймворку **Flask**.  
Використовується наслідування шаблонів, семантична HTML-структура, Bootstrap і власні CSS-стилі.
