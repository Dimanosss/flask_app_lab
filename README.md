# Lab3 - Flask проект з блюпринтами

Це Flask-додаток, створений на основі Lab2, з використанням блюпринтів для організації коду.

## Структура проекту

```
Lab3/
├── app/
│   ├── __init__.py          # Ініціалізація Flask-додатку та реєстрація блюпринтів
│   ├── views.py             # Роути, що не належать блюпринтам
│   ├── templates/
│   │   ├── base.html        # Основний шаблон
│   │   ├── index.html       # Головна сторінка
│   │   └── about.html       # Сторінка про проект
│   ├── static/
│   │   └── css/
│   │       └── styles.css   # Стилі для сторінок
│   ├── users/               # Блюпринт users
│   │   ├── __init__.py
│   │   ├── views.py         # Маршрути блюпринта users
│   │   └── templates/
│   │       └── users/
│   │           ├── hi.html   # Сторінка привітання (з вертикальним меню)
│   │           └── admin.html # Адмін панель
│   └── products/            # Блюпринт products
│       ├── __init__.py
│       ├── views.py         # Маршрути блюпринта products
│       └── templates/
│           └── products/
│               ├── list.html    # Список продуктів
│               ├── detail.html  # Деталі продукту
│               └── 404.html     # Сторінка помилки
├── run.py                   # Запуск додатку
├── requirements.txt         # Залежності проекту
└── tests/                   # Тести
    ├── __init__.py
    ├── test_user_bp.py      # Тести для блюпринта users
    └── test_product_bp.py   # Тести для блюпринта products
```

## Встановлення та запуск

1. Встановіть залежності:
```bash
pip install -r requirements.txt
```

2. Запустіть додаток:
```bash
python run.py
```

3. Відкрийте браузер і перейдіть на http://127.0.0.1:5000

## Запуск тестів

```bash
python -m unittest discover tests -v
```

## Маршрути

### Головні маршрути (не блюпринти)
- `/` - Головна сторінка
- `/about` - Про проект

### Блюпринт users (префікс `/users`)
- `/users/hi/<name>` - Привітання користувача
- `/users/admin` - Адміністративна панель

### Блюпринт products (префікс `/products`)
- `/products/` - Список продуктів
- `/products/<product_id>` - Деталі продукту

## Особливості

- Використання блюпринтів для модульної організації коду
- Шаблони з наслідуванням base.html
- Вертикальне меню на сторінках користувачів
- Стилізований інтерфейс з Bootstrap 5
- Повний набір тестів для обох блюпринтів
